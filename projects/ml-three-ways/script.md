## Facts and sources
- Main types of ML: supervised, unsupervised, reinforcement (plus generative AI). Supervised = data contains the correct answers; unsupervised = finds patterns, often by clustering similar data into groups; reinforcement = rewards or penalties for actions, used to train software like AlphaGo. Google, Intro to ML: https://developers.google.com/machine-learning/intro-to-ml/what-is-ml
- Spam vs not spam is a classic supervised example (learned from emails already labelled spam / non-spam). GitHub: https://github.com/resources/articles/what-is-unsupervised-learning
- Clustering customers by their buying behaviour (customer segmentation) is a common unsupervised use. Google Cloud: https://cloud.google.com/discover/what-is-unsupervised-learning
- ChatGPT: supervised fine-tuning first (trainers wrote example conversations), then reinforcement learning from human rankings (RLHF). OpenAI: https://openai.com/blog/chatgpt
- "Three main ways" = the three classic training categories; Google lists generative AI as a fourth category, so the reel says "main", not "only".
